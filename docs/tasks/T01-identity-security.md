# T01 身份与安全

用途：**公开任务基线**。按子任务标注阶段验收，M1 完成不代表整卡完成。进度管理、共同规则与依赖见[任务总表](README.md)。

## 目标

建立可追责的身份与会话模型，让所有领域命令和文件读取使用同一授权依据；把敏感操作的批准限制在确定的动作、对象和请求摘要内，并明确撤权与并发提交的生效顺序。

## 拥有模块与数据

| 模块 | 拥有的数据与边界 |
|---|---|
| `identity` / `policy` | `main.db` 中的主体、项目成员、角色、策略、凭据、认证因子、Challenge、HumanGrant 与批次授权项 |
| 身份会话适配器 | `runtime.db` 中由身份模块拥有的会话运行记录；T05 通过接口验证和关联会话，不直接修改认证记录 |
| 授权协调 | 认证上下文、权限修订、授权 guard 的策略；复用 T00 的命令协调框架，维护屏障由 T08 接线 |

不拥有 BlobGrant/ReadGrant、资源审定状态或任务租约；分别由 T02、T03、T05 管理，通过已定义接口提供所需授权事实。

## 子任务

| ID | 阶段 | 具体工作与产物 |
|---|---|---|
| T01.1 | M1 | 定义并实现人、Agent、节点、执行器、运行器和服务主体的注册、停用与项目角色；能力与角色分开；提供可信的 principal/session/project 上下文和用途检查，忽略客户端自报身份类别 |
| T01.2 | M1 | 实现本机一次性管理员初始化、密码/TOTP 登记和恢复码；支持受限的验证器恢复流程；已有实例缺库时进入恢复诊断而非重新开放初始化；密钥材料与事件/素材数据分开保存 |
| T01.3 | M1 | 实现长期凭据换取会话、范围收窄、到期和吊销；明确 `auth_epoch`、`recovery_epoch` 校验，禁止 Agent 凭据变成人类会话；对外提供会话验证及结束接口 |
| T01.4 | M1 | 将角色变更、权限收紧和最终业务接受接入同一协调顺序；撤权提交后新请求不依赖延迟缓存放行；提供 T02 下载检查和 T03 最终提交检查所需的只读授权接口 |
| T01.5 | M1 → M2 | M1 为凭据/策略管理实现动作摘要绑定的 Challenge/HumanGrant；M2 扩展到资源审定、解锁、限制解除和清除。批次逐项绑定稳定子操作 ID，支持过期重验证和已提交回执重放 |
| T01.6 | M1 → M2 | 建立授权、TOTP 重放/限速、受限恢复和并发撤权测试；M2 与 T03/T05 联测换目标攻击、迟到提交、批次部分完成和会话恢复；与 T07 完成 CLI/浏览器凭据处理，与 T08 校验敏感字段不进入日志 |
| T01.7 | M2 | 补最小项目里程碑与负责人配置，元数据在 main；进度经 T05 的任务查询计算，不跨库联表；项目上下文/决议内容归 T02，生效审定归 T03 |

## 依赖与并行方式

- 开始前：T00 固定身份/命令上下文、权限错误、事务组件和可控时钟契约。
- M1 联调：正式运行依赖 T08.1 的实例启动/五库迁移/维护屏障；T02/T03 消费授权接口，T07 装配认证 HTTP/CLI，T08 另接 TLS、密钥配置和恢复入口。模块本身可用接口桩先行验证。
- M2 联调：T03 提供精确审定/清除目标，T05 提供有效任务执行轮次；T01 不承担业务状态机。
- [T09](T09-extension-platform.md) 提供插件启用范围与有效实例事实；T01.3/.4 验证 actor 与插件委托身份、短期能力和当前权限，T01.5 在 M2 绑定包摘要/范围/配置的启停授权。网页 Cookie 写请求的 Origin/CSRF 防护与 T07 联验，浏览器插件不领取 HumanGrant。
- 传输优先级只向 T02 提供可信的主体/会话类别，不接受客户端自行声明“交互优先”；网关与监听配置归 T07/T08。

## 验收

- 空实例只能初始化一次；实例标记存在但库缺失时无法再次取得管理员权限。
- 同一成功 TOTP 时间步不可换取第二个挑战；过期、跨会话、改目标、改请求摘要均拒绝；限速不能靠创建新挑战绕过。
- 密码与恢复码只能进入受限恢复会话，不能直接审定、提权或下载资产；因子恢复后旧会话、旧 grant 和旧恢复码失效。
- 撤权成功后，新提交接受点和新下载请求均拒绝；在撤权前已完成的操作保留审计，不制造重复效果。
- M2：批次中已成功的项目只返回原回执，未成功项目仍核验当前权限；普通 Agent、节点、worker 和 runner 均不能通过人审 gate。
- M2：只有获授权负责人能变更里程碑配置；进度来自任务查询，跨项目任务不被混入统计。

## 范围外

企业 SSO、跨馆身份联合、通行密钥网页完整实现、任意第三方凭据托管；任务调度、文件签名地址和资源审定判定；防止拥有主机管理员权限的进程控制整机。
