# T03 台账与溯源

用途：**公开任务基线**。按子任务标注阶段验收，M1 完成不代表整卡完成。进度管理、共同规则与依赖见[任务总表](README.md)。

## 目标

明确资源命令何时生效、发生过什么以及为何允许使用；独立保存审定、发布和生命周期事实，确保文件恢复、流程重试和索引延迟不能制造重复或未经授权的业务效果。

## 拥有模块与数据

| 模块 | 拥有的数据与边界 |
|---|---|
| `ledger` | `ledger.db` 中的版本/占名控制、提交 operation、receipt/outbox、审定、发布、锁定、回收站与墓碑；每个命令的业务接受由本模块完成 |
| `provenance` | 版本依赖、许可快照、追加更正和 RightsAssertion 的领域模型与证据文件；通过 T02 文件接口保存，台账记录已生效修订与 rights_epoch |
| 验收记录 | Check/Profile、ReviewTarget、Waiver 及证据归属校验；T06 产生检查结果，T05 管理相关任务，T03 裁决结果可否用于审定 |

搜索/关系索引不是许可或删除授权来源；T03 不接管任务表、插件运行状态或身份凭据。

| ID | 阶段 | 具体工作与产物 |
|---|---|---|
| T03.1 | M1 | 实现命名空间占用、版本号保留与提交操作状态；调用 T02 安装接口后，在本库事务写版本登记、初始状态、回执和 outbox；相同操作恢复原 ID，证据不足的孤立目录进入核对 |
| T03.2 | M1 | 实现元数据/记录生效修订、不可变 uses 与许可快照；插件产物/证据固定插件 ID、版本与包摘要，按 T09 静态登记校验来源而不启动插件。限制判断使用固定版本引用及当前权威证据；同哈希多来源保留歧义，未知或无法完成核验的用途返回明确 pending/拒绝 |
| T03.3 | M1 | 与 T02/T01 联测幂等、过期基线、撤权、占名及崩溃恢复；提供 T04 的权威读取/枚举接口和 T08 的对账/恢复 hooks；证明索引不可用时已提交版本仍能精确读取 |
| T03.4 | M2 | 实现锁定/停用/归档、Trash/Restore/Purge/Hold 与墓碑命令；固定普通 30 天、宽限 3 小时/7 天、每小时 20/200 条及普通超过 50 条确认规则；整目录不豁免；先保存意图和清单再调用文件动作 |
| T03.5 | M2 | 实现 AcceptanceProfile、CheckResult、ReviewTarget、豁免和版本化人审；依赖 T05 的制作/质检/审定任务及 T06 的结构检查结果；证据必须绑定目标清单，质检按主体分离，批次授权不得扩大目标 |
| T03.6 | M2 | 实现自动请求发布、手动发布、暂停、回滚及审定撤销；新版批准不提前改变旧发布指针，撤销当前有效批准时同台账事务暂停发布；RightsAssertion 收紧/解除留证据和授权，向 T05/T04 发事件 |

## 依赖与并行方式

- 开始前：T00 固定领域命令、安装证明、持久 operation、限制查询和错误模型。
- M1：T01 授权、T02 内容存取以桩先行，再共同集成；T03 不要求 T02 整卡完成，T02 也不等待 T03 的 M2 审定能力。
- 正式提交/恢复测试依赖 T08.1 的实例启动、五库迁移和维护屏障，不能只在模块内数据库上宣布 M1 集成通过。
- M1 恢复/查询验收分别与 T08/T04 集成，事件投影失败不能回滚已确认的台账结果。
- M2：审定验收必须接入 T05 的有效任务轮次与 T06 的真实合成检查产物；纯桩可验证领域状态，不可替代 M2 的制作→检查→质检→返工→人审闭环。
- T07 提供人审 CLI/API；T01 验证 HumanGrant，T03 再校验业务目标 revision、证据和状态。

## 验收

- M1：prepared 后重启不重新分配版本号；committed 后响应丢失不生成第二版本；同键异摘要、旧基线分别返回确定冲突。
- M1：普通著录或删除依赖边不能擦除旧许可证据；当前限制收紧而索引滞后时仍阻止禁止用途，未知来源不自动获得最宽许可。
- M2：旧版已发布、新版仅批准时，当前发布仍是旧版；自动发布失败可独立重试；回滚保留全部发布历史及实际使用版本。
- M2：旧审定卡片、错误 manifest、不同检查器版本和未经授权豁免均无法通过；撤销误批准后重放旧发布命令不能重新激活它。
- M2：使用可控时钟验证 3 小时、7/30 天、滚动配额和提前清除；被引用/锁定/已发布对象不因宽限而放行；整目录始终人确认，Agent 永不能清除。
- M2：恢复保留内容与审计事实，不复活旧租约/流程或旧审定目标；与 T05/T06/T07 完成一次退回返工、再次批准、发布和精确拉取的联合验收。
- M2：讨论和评论继承目标对象的可见范围；重复发送不生成重复消息；一条 answer 或 decision_proposal 不等于已批准审定或已生效决议。

## 范围外

通用工作流引擎、Agent 自动运行器、检查插件算法、自动法律兼容性判断、定时发布、媒体预览平台；历史数据扫描或批量导入的执行。迁移映射只保留契约扩展点。
