# T07 — REST、薄 CLI 与 MCP

状态：**待确认 / 未开始**。按子任务标注阶段验收，M1 完成不代表整卡完成。共同规则与依赖见[任务总表](README.md)。

## 目标

让所有客户端通过同一套应用规则操作兰台。M1 即交付能真实完成认证、上传、提交和精确版本拉取的 REST 与薄 CLI；M2 扩展任务、人审和 MCP，客户端只适配输入输出，不裁决权限或业务状态。

## 模块与数据归属

| 模块 | 职责与归属 | 不拥有的数据 |
|---|---|---|
| HTTP transport | OpenAPI 请求/响应、认证上下文传递、错误映射、请求编号、请求体限制、接口/传输路由及 HTTP server 配置 | 不直接写五库；幂等回执、授权和状态转移由所属应用模块处理 |
| CLI / SDK | 命令解析、薄 API 调用、本地文件搬运、两套连接池、可恢复传输信息和结构化退出结果 | 不复制权限矩阵、状态机或发布规则作为裁决逻辑 |
| MCP stdio | 调用同一 REST，输出受控结构化结果、引用和任务 ID | 不传原件字节、不持有人的敏感操作授权、不提供终审/清除/任意 shell 工具 |

采用已确定的流量分面方案：对外一个网关入口；M1 同一 Go 进程内分设接口面 `/api/` 与传输面 `/xfer/` 的监听和限额，不按人、Agent 或网页分端口。运维面仅本机可达且不经网关；独立长连接面留 M7。

T07 提供 transport 路由与监听构造配置；T08 负责同一进程中的启动/关闭、网关转发、TLS、监听绑定和 readiness 汇总。双方交付联合验收，不能把分面实现成多个业务服务或不同授权通路。

## 依赖与协作

- T00 负责工程级契约、生成工具版本和 schema 演进规则；T07 落地 transport/client 并把契约问题反馈给 T00。
- T07.1 与 T08.1 在 T00 后先行；T01–T04 依赖契约并行实现，不等待整张 T07 完成。
- M1 的 T07.1–T07.4 与 T01 身份、T02 上传/存储、T03 版本台账、T04 查询/事件、T08 服务生命周期逐项联调；可使用契约桩，但 M1 交付必须换成真实纵向接口。
- M2 的 T07.5–T07.6 接 T05/T06；CLI/MCP 不实现第二套 lease、预算、审批或发布状态机。外部事件消费和长轮询沿用 T04 游标规则；M7 才实现独立推送面。
- [T09](T09-extension-platform.md) 定义扩展包治理、命令和路由贡献；T07.5/.6 接线显式 CLI/MCP 入口，不自动执行 PATH 同名文件。服务 API 仅注册已声明方法/schema，不提供任意代理；网页来源与 broker 规则见[扩展设计](../extensions.md)，后续与独立网页工程联调。

## 可测验收

| 场景 | 通过条件 |
|---|---|
| M1 无任务引擎的纵向存取 | 从 CLI 经 REST 完成会话、上传、提交、精确版本拉取；哈希一致，具有 operation 和审计；不依赖尚未启用的 M2 Flow。 |
| 同一操作重复/冲突 | 响应丢失后同键返回原操作；异摘要、过期 ETag、越权请求在 CLI/REST 中得到一致机器错误；客户端不自动扩大权限。 |
| 1 GB 传输中断后恢复 | 续传完成并逐文件校验；进程内存不随文件总大小线性增长；取消只影响目标传输，接口请求仍可完成。 |
| 流量隔离 | 3 个合成客户端批量上传/拉取时，接口面 p95 起始目标不超过空载基线 2 倍；交互请求优先于排队批量请求。记录环境与实测结果，调整阈值须留下依据。 |
| 通路与授权一致 | merged 与分面监听返回同等授权/错误；只有 URL 或哈希不能下载；接口大小限制不截断合法分片流，传输请求不能绕过授权。 |
| M1 三平台与恢复门禁 | 与 T08 在 Linux、macOS、Windows 完成规定的服务/CLI 存取冒烟及中断恢复用例；恢复后旧 epoch 会话/租约失效，原操作可查询，已提交版本仍可精确取回。流量隔离、三平台和恢复任一门禁未通过，不声明 M1 完成。 |
| 暴露范围与 MCP | 网关只暴露获准业务路径，远端访问不到指标/诊断；MCP 与 CLI 相同用例结果一致，结果不内联大文件、不泄漏凭据，不出现终审/清除工具。 |
| 最小 Python SDK | 同一合成认证/资源/任务用例与 REST、CLI 的结果及错误码一致，重新生成无未解释差异；不存在私有 API 或直接读取数据目录的入口。 |

## 范围外

T07 不负责领域实现、数据库迁移、实际服务器部署或网页产品。M1 不开放第二个外部传输端口；如后续实测触发既定评估条件，再单独评审路由、TLS 与跨源行为。M2 不部署远程公网 MCP、IM、馆际接口或 M7 推送面，也不为不同客户端维护私有 API。
