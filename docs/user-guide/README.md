# Lantai 用户手册

从你要完成的事情开始。这里的步骤面向使用者和设备管理员；技术协议另见[文档导航](../README.md)。所有网址、姓名、路径和输入样例都是合成数据，使用时替换成自己的值，不把凭据发到聊天或问题单。

适用基线：**v0.1.0-rc.3，9bf4b56b08deb4e5ea6ba4f294629e51df1bc9f9**。文档核对日期：2026-10-13。本文不证明任何现有 NAS 已完成升级。页面显示的文档版本也不代表服务器实际版本。

## 先认清三个位置

- **NAS** 保存服务、资料卷和密钥卷。NAS 文件管理器里的项目配置目录不等于资料卷。
- **浏览器** 用 HTTPS 地址访问服务。rc.3 的 `/setup/` 仅用于首次初始化，完成后永久关闭；根路径 `/` 返回 404 可以是正常现象。
- **自己的电脑** 运行 Lantai CLI、Codex 和本地工作目录。`--directory`、`--workspace`、会话文件都属于这台电脑，不是 NAS 路径。

## 已有能力与开发中的页面

rc.3 已有受保护的首次设置页、REST、CLI、stdio MCP、离线共同备份及空目录恢复。独立业务前端的首页、登录及项目资源浏览另在开发；本手册不把尚未发布的按钮写成可用入口。需要浏览资源时先用[现有 CLI 步骤](daily.md)。

网页在线备份入口、运行中备份的主动取消、外部盘自动预检、安装/升级全过程的卷身份绑定保护均仍是设计。现有本机 `backup -cancel` 只能在取得锁后取消记录，不等于可打断另一个正在运行的备份进程。详见[能力边界](backup.md)。

## 阅读与保存

随前端部署后的帮助入口为 `/help/`，可搜索本手册、按目录跳转或用浏览器打印保存。该帮助目录是公开通用内容，不读取会话、项目或服务器配置。rc.3 原始部署模板没有这个路由，访问 404 时可直接阅读仓库中的本手册；不要因此重装实例。
