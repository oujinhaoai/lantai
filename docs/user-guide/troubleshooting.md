# 常见问题与版本兼容

先保留发生步骤、时间、非秘密回执、错误码和 request/operation ID。普通使用者优先按下面的界面路径处理，无需先阅读 API 或代码。不要提供口令、动态码、TOTP 密钥、恢复码、会话文件、私钥、完整私有配置或临时下载授权。

## 创建了项目却看不到

先看“系统管理”里的“服务器操作回执”。有 project_id、created_by 表示已登记的事实；description_pending=true 或 description_error 表示说明尚未完整生效。管理员创建项目不会自动取得项目资料角色，“我的项目”按 ACL 过滤，所以列表不见不能单独判定创建失败。

用回执 project_id 在“成员管理的明确项目标识”中点“读取此项目成员”，核对本人角色，再按职责授予 viewer 或 contributor，并核对最新修订。填写项目 key、名字或猜测的 ID 不会代替稳定标识。详见[创建项目与权限](accounts.md)。不要重复创建、直接升 owner、重新初始化或清空资料卷。

## 有角色仍不能写入

viewer 主要用于读取。contributor 可按规则提交自己的资料，但当前浏览器会话还需明确选择“素材写入与整理（迁移、工作集档案和信息编辑）”以申请 ingest/organize。已登录会话不会自动加范围，应退出后重新选择；勾选管理员登录也不自动授予项目角色或写入范围。涉及他人素材、审定或发布仍须各自职责与动作授权。

## 保存工作集后列表找不到

先确认“固定记录”回执已经返回，并检查说明是否 pending。显式点“读取项目工作集记录”；列表是本次查询的观察，刚保存后可能尚未追平索引，稍后再次点同一查询。核对归档项目、权限和返回的档案 ID，再从列表重开并复验。固定 ID 后备打开可帮助对账，但不能把列表发现失败那项改为通过。持续缺失时保留回执与原状态，交接错误，不另存一份掩盖原操作。

## 常见错误与停止条件

| 看到什么 | 按界面先核对什么 | 停止与下一步 |
| --- | --- | --- |
| 登录失效、TOKEN_EXPIRED | 当前本人会话和勾选范围 | 重新正常登录；不初始化新实例 |
| TOKEN_REVOKED／FORBIDDEN／NOT_FOUND | 同一实例、项目角色、会话范围和当前 rights | 联系有权管理员核对；NOT_FOUND 可是权限过滤，不猜 ID 或自动扩权 |
| TOTP_REPLAY | 刚用于登录或授权的时间步 | 等验证器换码，不保存动态码或关闭 TOTP |
| HUMAN_PROOF_REQUIRED／HUMAN_GRANT_MISMATCH | 确认框的动作、完整目标、修订、会话与有效期 | 冻结原请求先核对，不把旧授权套给新目标 |
| description_pending=true | 服务器回执的已提交身份、说明错误及 organize 范围 | 记录部分成功，保留原状态与键；不新建项目或重传资产 |
| 修订冲突／412 | 当前著录与自己保留的原草稿 | 停止覆盖，由本人重读合并；文件版本与著录修订分开记录 |
| IDEMPOTENCY_CONFLICT | 原输入、原状态、原键 | 先恢复原绑定输入并对账，不换键制造重复提交 |
| 下载/解出文件 SHA-256 不符 | 固定版本、实际文件大小、编码与完整摘要 | 停止使用该副本，保留证据；点击下载或预览通过不能替代字节检查 |
| 备份失败／取消中／interrupted | 原 job.id、备份目录状态与当前阶段 | 等实际退出；修复后沿“续传此任务”，不伪造完成或换包续传 |
| 备份 complete 但未做恢复 | 是否有独立目标、恢复接受、重读及重启证据 | 恢复记未测，不以备份生成代替恢复通过 |
| 网关502／core反复退出／旧schema拒启 | 设备管理员的原卷、兼容核心及迁移报告 | 停写并保留现场；不删卷、删锁或放宽版本守卫 |
| TLS或主机名错误 | 原服务地址、证书、时间及受信CA | 停止，修复配对；不跳过证书验证 |
| 非空恢复目标／restore_incomplete／摘要错误 | 获准的空目标与恢复状态 | 保持业务关闭；不覆写原数据或强行完成恢复 |

## 版本与恢复边界

r11 是 Web 候选，兼容核心以该 Web 包 manifest 为准；帮助显示 r11 不代表服务器程序也已更新。历史 rc.2/rc.3 没有当前业务/帮助路由，旧 rc.4 也没有当前管理页。网页缺失时核对静态包、只读挂载与网关，不能仅换 core 或重装数据卷。

更高 schema 不能用旧镜像同卷降级。rc.6 格式独立卷恢复涉及 recover-admin、绑定证据的 restore-complete 与目标自己的配置；NAS 纯 GUI 旧版恢复仍未验证，本次 Web 更新没有补齐它。请按[更新网页](upgrade.md)与[恢复边界](backup.md#恢复验收的边界)分别处理，不把 Web 文件回退当作数据库回滚。

## 向维护者交接

使用[空白验收记录](acceptance.md#空白验收记录)，给出兼容核心/Web manifest、实际入口、合成输入范围、预期与实际、非秘密回执、错误码和已停止的步骤。不能确认的事项写“未测”或“阻塞”。私有 ID、路径与附件留在批准的私有记录中，公开问题只提供脱敏最小复现；不夹带生产配置或凭据。
