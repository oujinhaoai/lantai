# 隔离恢复演练

`serve-drill` 用于在独立的本机恢复副本上验证恢复后的身份、固定版本读取及受限本地操作。源实例可以继续在线。它不是正式接管，不确认备份之后的撤权、删除或外部副作用已经对账，也不解除正式恢复门闩。

当前支持 Linux 和 macOS；其他平台因尚未实现可靠的共享文件检查而拒绝开启演练。交叉编译不代表该平台演练通过。

## 准备与启动

1. 将完整恢复包恢复到全新的本地目录，或对已离线恢复且停止使用的副本做独立复制。不要使用正式数据目录、共享数据库、硬链接、符号链接或网络挂载。APFS 写时复制可以使用，但每个文件必须有独立 inode。
2. 保留原始恢复副本和备份。演练会写入专属标记、登录状态、查询索引和演练操作；这些结果不能当作生产事实。
3. 用现有 `recover-admin` 在演练副本重建管理员。使用只用于演练的新密码与验证器，妥善保管恢复码；不能复用备份中的旧凭据。
4. 使用独立入口启动，所有监听都指定数字 loopback。以下端口 `0` 由系统分配，实际监听地址从启动 JSON 读取。

```sh
lantai restore -home <empty-drill-home> -backup <complete-package.lantai>
lantai recover-admin -home <drill-home> -admin <administrator-name>
lantai serve-drill -home <drill-home> \
  -api-listen 127.0.0.1:0 \
  -transfer-listen 127.0.0.1:0 \
  -operations-listen 127.0.0.1:0
```

本机 HTTP 客户端须显式允许 loopback HTTP，并使用演练副本的新会话。不要改全局客户端/MCP 配置指向演练副本，不要把演练端口接到网关、反向代理、隧道或公共网络。验收结束停止进程，不把它作为常驻服务。

## 不可误作正式接管

首次演练打开在数据根安装 `recovery-drill.json`，绑定该目录、实例、恢复 run、备份摘要和恢复代际。移动目录、替换恢复标记、代际不符或损坏的演练标记均拒绝启动。

原 `instance.json.restore` 门闩保留。正常 `serve` / `start`、正式 `restore-complete`、备份和升级不能把演练数据转为正式实例。要正式接管，应从保留的完整包向另一个空目录重新恢复，并完成正常的源停机、管理员重建和恢复点确认流程。不要删除或改写标记来提升演练副本。

启动输出和 HTTP 响应标识演练状态及 `unknown_after_capture`。该状态意味着备份捕获之后的真实变化仍未知，不是自动对账通过。`doctor` 仍会看到正式恢复未完成；演练就绪与生产可接管是两种不同结论。

## 隔离边界

- 开放监听前验证目录树，拒绝符号链接、共享硬链接、特殊文件、跨设备目录及外置密钥目录；只允许已完成凭据轮换且保留对账门闩的恢复实例。
- API、传输和运维只绑定数字 loopback。请求还检查本机目标与来源；公网 Host、跨站 Origin、转发头和未明确允许的路径拒绝。
- 仍使用现有真实身份、当前权限、固定版本与文件摘要检查。管理员身份不自动给予项目读取权。旧会话、机器凭据和旧恢复代际不会恢复权限。
- 不组装外部扩展宿主、Job 执行器、节点或业务自动调度；不启用生命周期清除、自动备份或后台任务派发。未知接口默认拒绝。
- 本版只允许登录/退出、已有项目与资产/固定版本读取和文件 read grant，以及本地任务的创建/领取/续租/释放/阻塞/取消、manual task-run 的开始/进度/检查点/取消与查询。这些仅记录副本状态，不会运行 Agent、DCC 或外部检查器。
- 不开放上传/入藏、Flow 派发、Job/扩展/设备执行、真人管理命令、发布、清除或整馆备份。未知路由默认拒绝；`/meta` 标示受限能力，不能按普通实例能力推定演练全部可用。

这是应用层防误用隔离，不是操作系统网络或文件沙箱。同一 OS 用户可以替换程序或改写文件；此模式不防御恶意本机管理员，也不能阻止另一个工具读取副本后主动上传。不要用旧程序或手改数据绕过边界。需要对不可信程序执行做演练时，应另建可实证的无网络容器/虚拟机，不把 loopback 当作执行沙箱。

## 验收与证据

合成回归入口：

```sh
go test -race ./internal/operations ./internal/application ./tests/integration \
  -run 'RecoveryDrill|Drill' -count=1
```

其中任务场景验证活动 run 重启后继续记录进度、重复请求幂等、真实租约到期拒绝以及检查点写入后重启仍保持相同绑定；不把检查点持久化写成新 attempt 的完整恢复执行。

分别记录以下结论，不能互相替代：

1. 完整包校验与离线恢复：恢复点、原件数量/字节、逐文件摘要、五库完整性、旧身份撤销。
2. 隔离模式安全：错误数据目录、链接/外置密钥、非 loopback/代理请求、外部执行与普通启动拒绝；正式恢复门闩不变。
3. 新管理员恢复与 HTTP 读取：实际重新设置认证、成功新登录、旧凭据拒绝、固定历史版本与字节核验、权限拒绝。
4. 受限续办：保留同一任务/operation 的本地合成场景、重试/重启/过期 fence 拒绝。原备份没有相应样本时，必须注明是独立合成测试。
5. 正式接管：源实例停机、最新撤权/删除/副作用对账、目标部署及运行验证。`serve-drill` 不能完成或代替这一项。

本机开发测试不证明 NAS 断电、磁盘故障、长期 RPO 或真实制作工具续做已经通过。
