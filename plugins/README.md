# plugins · 官方扩展包

归属：[T09 扩展平台](../docs/tasks/T09-extension-platform.md)负责统一包与宿主契约；[T06 执行与节点](../docs/tasks/T06-execution-nodes.md)负责处理器/Agent 的业务调用。

M2 先实现一个可重复验证的结构检查插件及宿主协议；M3 按能力扩充媒体与 3D 处理器。源码、依赖说明、插件清单和测试随各插件维护，语言按处理工具选择。

插件只接收获授权输入，输出结构化结果、摘要与证据，不能直接访问核心五库或规范素材目录。协议 schema 在 `schemas/`，宿主实现属于 `internal/`。大文件及第三方模型权重不随目录占位加入仓库。

目录同时容纳官方服务端/节点、CLI 和网页贡献包及示例，各 target 分别启用。网页宿主和首方应用组件在 web，不把整个网页应用放入插件目录。统一清单、配置 schema 和版本规则见[扩展设计](../docs/extensions.md)；T09 按 M1 静态注册、M2 进程与 CLI、M3 网页分期。开发仍待确认，本目录不自动安装或运行插件。
