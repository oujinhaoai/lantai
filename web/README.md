# web · 兰台管理工作台

TypeScript / React / Vite 独立静态网页，只调用同源 `/api/v1/`。五个入口为素材库、迁移中心、工程工作集、备份与恢复、系统管理；原首页、项目和帮助入口保留。入口、业务范围、失败处理及预算见[管理工作台指南](../docs/user-guide/admin.md)。此为开发候选，发布、浏览器与目标设备验收单独记录。

素材库提供服务端组合搜索、精确标签 AND、逐版本实时授权的历史分页、固定清单比较和 If-Match 著录编辑。迁移中心支持显式清单、分组/rights/容量预检、原键续办、固定版本逐文件验证，以及计划/结果的馆内 config 档案。工作集固定版本和依赖，可在预算内下载 TAR，或导出受控本机助手作业。备份页复用原协调器，恢复证据只关联核心真实完成回执与本次所选版本验证。系统页复用原成员、人审、发布、生命周期与审计接口；HumanGrant 绑定冻结动作，未知结果保留原操作。

`/#/assets/<asset-id>?version=<version-id>` 固定版本不回退最新版。当前著录与冻结清单分别显示；访问、ReadGrant、读字节与摘要均重新核验。管理档案以明确确认的私人记录条款保存，不修改原素材权利，也不保存会话、HumanGrant 或传输授权。浏览器原操作状态须显式下载保管，丢失后不能凭推测换键恢复。其状态格式不承诺任意 CLI RawMessage 词法互导；会损失数字/转义/键序的原生计划拒绝经页面重编码，须保留原文件并用助手 input_file 交接。

## 构建

Node.js 24（CI 固定主版本）、npm；Go 工具链由仓库固定。依赖精确版本见 package.json 和 package-lock.json。

```sh
cd web
npm ci
npm run test:unit
npm run lint
npm run build
```

产物是 web/dist，不需要运行 Node 服务。生产环境由已有 HTTPS 网关提供静态文件，与 API 完全同源。路由使用 `/#/assets`、`/#/migrations`、`/#/worksets`、`/#/admin/backups`、`/#/admin/system` 以及原项目入口，刷新或深链接无需 catch-all；未知 API 和运维地址仍返回 404。

`npm run dev` 只监听 loopback，向 127.0.0.1:8080 代理 API。真实登录仍要求 HTTPS/安全 Cookie 与精确允许的 Origin。不要为 HTTP 调试关闭 Secure、TOTP 或来源校验。可重复验证优先使用自带 HTTPS 合成实例。

## 浏览器验证与预览

```sh
cd web
npm run build
npx playwright install chromium webkit
npm test
```

测试自动启动 Go TestWebBrowserFixture，使用临时真实实例、SQLite、文件存储、随机主密钥、合成管理员和资源；不读取实际实例配置或凭据。Chrome、手机 WebKit 与平板 WebKit 覆盖登录、Cookie、CSRF、中文搜索、分页、详情、导航、空数据、撤权、过期、失败、重复提交和迟到响应，含横竖屏、长文件名、触控目标与键盘焦点，另以 axe 扫描登录/首页/检索/详情的 WCAG 2.1 A/AA 自动规则。自动扫描不替代屏幕阅读器和真实设备人工验收。自签名 TLS 仅测试上下文接受；不修改系统证书信任。测试结束关闭实例。

独立保留本机预览：

```sh
# 仓库根，只用于合成测试，不绑定外部接口
LANTAI_WEB_FIXTURE=1 go test -tags=lantai_test_hooks -run '^TestWebBrowserFixture$' -count=1 -timeout=30m ./tests/integration
# 另一个终端在 web/ 执行以复用实例
LANTAI_WEB_REUSE=1 npm test
```

地址 https://localhost:4180。它不使用真实凭据，测试工具通过仅存在于测试二进制中的控制接口生成合成登录输入。不要将此服务用于部署。`LANTAI_WEB_EVIDENCE=/path/out npm test` 保存不含登录输入的截图。测试不自动重试 TOTP。

## 认证与数据边界

- 登录固定 channel=browser，普通浏览只申请 self/read。显式勾选素材管理时申请 ingest/organize，勾选管理员登录时另申请 admin；服务器仍核验真实管理员角色。服务端发 Secure/HttpOnly/SameSite=Strict/host-only Cookie，JS 不读取会话令牌，也不接收主密钥或长期凭据。备份敏感操作的短时 HumanGrant 仅保留在当前确认框内存，不写入浏览器存储。
- CSRF 值与会话 ID 只存在当前标签页 sessionStorage（存储受限时在内存）。刷新先用 whoami 复验；CSRF 必须匹配会话 ID。新标签页利用 Cookie 浏览；没有 CSRF 时提示回原登录标签页退出，或手动重新验证，不声称清 UI 就已结束服务器会话。
- 退出走既有 DELETE /sessions/current，带原有 CSRF。过期/撤销清空视图和 CSRF，不自动签发、交换或续期。返回应用时复验身份，新页面/筛选向服务端请求，不持久化业务数据，无 Service Worker 或离线缓存。
- 页面切换取消旧读取并卸载旧视图，迟到结果不装入新视图。分页显式加载下一页；过滤后空页仍允许继续，游标失效后回第一页。
- 用户字段作为文本渲染，无外部 CDN、埋点或第三方脚本。CSS/脚本均同源，网关静态路由提供 CSP 与禁止缓存头。
- 第一版没有权限自动推送。已展示的字节不能收回；刷新与新请求由服务端重新过滤。不引入全馆计数、隐藏项数量或权限推断。

## 部署接线

[compose.web.yaml](../deploy/compose.web.yaml) 只把 `LANTAI_WEB_DIR` 指定的已核验静态目录以只读方式挂到现有网关，不修改核心镜像、数据/密钥/首次设置卷。现场升级与发布新版本须另行审查，本仓库构建不会自动部署。

第三方网页和未来 UI 插槽仍遵守[扩展规格](../docs/extensions.md)，本版不激活扩展脚本。

## 管理员备份页

使用管理员账号登录时勾选“管理员登录（含备份管理权限）”，再打开主导航的“备份与恢复”。只有普通、人类、非委托的浏览器管理员会话可见入口；真实权限由每次 API 请求核验，隐藏入口不作为访问控制。现有管理员以普通浏览范围登录时，需重新登录以取得管理范围，页面不会自动扩大权限。

- 页面显示目录可用性、当前真实阶段、上次成功、按创建时间排序的任务历史（每次显示 10 条）和最近 20 条计划执行记录。目录配置错误不会使整个网页或正常 core 启动失败。错误提示只包含公开的分类及请求编号，不提供配置编辑、任意路径或密钥入口。
- 立即备份、续传及保存计划先取得服务器挑战，完整显示摘要和目标，再请本人输入新的 TOTP。冻结的请求与短时授权、幂等键一同提交；网络结果不明时可以使用同一个授权及键重试，不能自动创建第二个备份。取消使用既有 Cookie/CSRF，不额外索取动态码。
- 所有业务读写在备份期间暂停，备份状态、历史、取消和身份读取仍可用。页面在任务执行期间每 2 秒查询状态，空闲每 15 秒查询，失败时逐步退避至 30 秒；离开页面会中止读取，不保持业务响应缓存。取消或超时仍须等待实际工作退出，界面不会提前报告恢复。
- 如果普通会话在备份中失效，从登录页选择“备份期间重新验证管理员身份”，重新输入账户、口令和新的 TOTP。独立的维护身份只允许查看备份和取消当前任务，不显示业务导航、开始、续传或计划编辑。其 Cookie 与 CSRF 不同于普通会话，CSRF 仅在页面内存；刷新通过专用受保护接口恢复。维护身份最长 10 分钟，绑定当前任务及尝试次数，任务结束或 core 重启后失效，不延长旧会话。返回普通业务需要重新正常登录。
- 每日计划保存当地 `HH:MM`、IANA 时区、排空等待上限和总超时。计划持久保存在 core，不依赖浏览器在线或人的登录令牌；启用者的管理员权限会继续核验，撤权后停止自动执行。修改计划基于草稿起始修订号，发现别人更新时提示显式重置，避免轮询把旧草稿升级为新版本后覆盖他人修改。
- 错过和忙碌时不排队补跑，同一当地日期最多自动运行一次；夏令时缺失时间跳过，重复时间只运行一次。core 重启保留计划，将未完成任务标记为中断；续传需管理员检查原因后再次确认。精确调度与错误分类以[备份管理 API](../api/backup-management.md)为准。

浏览器回归命令为 `npm test -- tests/backups.spec.ts`。它复用真实 HTTPS 临时实例验证管理员登录、备份完成、计划持久化、真实在途操作排空时的取消/续传及网络重试的授权绑定；UI 拒权、并发编辑、卸载取消和异常提示另以受控响应验证。Chromium、手机 WebKit、平板 WebKit 均执行同一用例，截图可用 `LANTAI_WEB_EVIDENCE` 保存。此测试不连接 NAS，不替代目标目录权限或现场恢复验收。

Playwright 自动启动的合成夹具使用 `lantai_test_hooks` 构建标签，在真实复制阶段设置受控等待点以验证会话过期后重新认证、取消后不提前恢复。该钩子不进入普通构建或发行二进制。键盘测试覆盖弹窗焦点约束/返回、取消与续传，持久 `aria-live` 区域播报真实阶段和操作结果；自动可访问性检查不等同于真人屏幕阅读器听读验收。

## 独立帮助页集成约定

帮助任务只维护 `docs/user-guide/` 与 `web/public/help/`；主应用拥有认证、布局、导航和网关。入口为普通静态路径 `/help/`，资源使用相对路径，不依赖 React、Cookie 或业务 API。现有 CSP 不接受内联脚本/样式，建议 `index.html` 配合同目录外置 CSS；不放宽主应用安全策略。

构建时只有检测到 `web/public/help/index.html` 才显示“使用帮助”链接；帮助文件尚未合并时不展示死链接。Vite 将 public/help 原样产出到 dist/help，Caddy 显式开放 /help 与 /help/*，不放开未知 API 或运维路径。帮助内容合并后，按 `python3 docs/user-guide/build.py --check` → `npm run lint --prefix web` → `npm run build --prefix web` → 真实 Caddy 联合验收的顺序检查。`scripts/check.sh` 在帮助构建脚本存在时先校验生成物，再执行 Web lint/build。联合验收需覆盖帮助存在/缺失、无 JavaScript、主应用条件入口、CSP、资源及 API/运维路由隔离，不能以本次预留接线声明帮助内容已发布。

## 只读文件展示

- 列表只显示类型图标与著录摘要，不自动请求原件或缩略图。详情优先选择符合现有类型与体积上限的主文件（文档优先 README），不支持的文件仍完整保留在选择器；只有不支持文件时只显示信息。选择文件后显式点击预览，使用现有 `archive_review` 读取用途；下载单独申请 `raw_export`。服务端用途限制仍可拒绝请求，不自动换用途绕过。
- PNG/JPEG/GIF/WebP/AVIF 使用原生图片元素，原图大于 16 MiB 时仅提示和下载。MP3/WAV/OGG/M4A/AAC/FLAC 与 MP4/WebM/MOV/M4V/OGV 使用原生音视频控件，`preload=metadata`、不自动播放；具体编码由浏览器支持，失败显示降级提示，不自动转码。列表不请求原件。`preload=metadata` 只是浏览器提示，原生播放器可能自行读取更多甚至整个文件；当前未验证大媒体播放前的传输量或取消点，也不保证音视频下载字节上限。独立 Range 测试只验证服务端支持授权分段读取。
- txt/md、py/go/js/ts/html/css 等代码、json/yaml/toml/ini 等配置只读显示。UTF-8 严格解码；首次最多 64 KiB，手动分段扩展至 256 KiB，最多显示 2000 行，截断明确提示。较长文本停止高亮以保持响应，源码始终可选取与复制。
- Markdown 使用 react-markdown 默认安全 AST 渲染并禁用 HTML；图片与链接仅作为文字显示，不自动请求任何内嵌资源。提供阅读/源码切换。代码高亮使用 lowlight AST 映射为 React 文本节点，不注入 HTML。HTML/SVG 只显示源码，不执行或嵌入。
- ZIP/RAR/7z/TAR 等压缩包、PDF/Office 与其他未支持的二进制仅显示基础元数据与提示，不解压、不执行、不做十六进制展示。误命名为文本的压缩签名、控制字节和未知编码同样降级。
- 短时读取地址只保留在当前视图内存，不写入存储。页面或文件切换中止旧读取；过期移除预览，不自动续期。没有当前标签页 CSRF 时提示重新验证。下载链接仍要求本人同一会话，转发 URL 不提供权限。

媒体兼容性必须以实际浏览器测试为准；合成 PNG、WAV、H.264 MP4 是测试基线，列出的其他后缀不代表所有编码都可播放。文件展示不提供在线编辑、代码执行、解压、第三方文档查看器或跨源资源代理。

## 有界素材工具

PNG/JPEG/WebP 缩略图和 PNG 代理：原图≤16 MiB、≤16,777,216 像素；输出最长边分别为320和512/1024/2048。生成前按 archive_review 完整验证，导出需新的 raw_export 授权。OBJ 线框≤2 MiB、20,000 顶点、60,000 边，不加载MTL/外部纹理。未知3D、原生工程编辑、通用转码、AI分类、双向同步、跨馆和自动删源均未实现。

`npm run test:unit` 使用锁定 TypeScript 的 Node 加载器执行模型/协议负例；真实浏览器脚本是另一门槛。某环境 Chromium/WebKit 不可安全启动时记录阻塞，不能用编译、单元测试或浏览器用例收集代替实际页面通过。
