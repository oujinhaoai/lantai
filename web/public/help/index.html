    开始使用文档核对 · 2026-10-21

    Lantai 用户手册

    先按界面完成手头的操作，再核对结果。已有服务的验收人员从人工验收步骤开始，无需先阅读 API 或代码。所有名称、文件和输入示例均为合成数据；不要把示例当作生产许可或已完成的验收记录。

    本手册属于 r11 Web 候选，兼容已交付 r10 核心。这是导航与帮助更新，不升级核心或数据库。准确提交、Web 摘要、兼容核心与测试范围见同包 manifest。本文不证明任何 NAS 已完成部署或完整恢复验收。

    开始前

    1. 用设备管理员提供的原 HTTPS 地址打开兰台，核对实例和配对版本。证书或主机名错误时先停止，不跳过安全提示。
    2. 准备自己的账户与验证器。口令、动态码、恢复码、会话文件、私钥和下载授权均不进入验收记录。
    3. 仅使用专门批准的合成测试项目与文件。需要创建项目时，先读创建项目与权限，不要因列表为空重建管理员或清空数据。
    4. 侧栏依次为“首页”“我的项目”“素材库”“迁移中心”“工程工作集”，再按权限显示“备份与恢复”“系统管理”；“使用帮助”在侧栏可直接找到。

    从界面到人工验收

    先完成“创建项目与权限”，再用五入口操作指南中的同一份合成文件走一条小范围闭环。每步都写下预期与实际：看到入口、点击按钮、收到提交回执、下载字节完整、独立恢复重开是不同结果，不能合并勾选通过。

    当前标题、摘要和画像的 r1→r2 是著录修订；固定文件的 version_id 是另一件事。工作集保存为 config 档案也会有自己的资产与版本 ID。请逐项记录，不用一个“版本2”代替三种身份。

    阅读与保存

    帮助入口为 /help/；每页顶部“人工验收”可直达操作清单，“返回兰台”回到同一站点。目录、正文、页内锚点和前后页在关闭 JavaScript 后仍可阅读；搜索需要 JavaScript，且只搜索本地公开帮助，不访问你的项目。

    需要交接时可用浏览器打印保存手册，并复制空白验收记录。帮助是公开通用内容；私有项目 ID、路径和验收附件只留在批准的私有记录中。
