    先认清三个位置

    • NAS 保存服务、资料卷和密钥卷。NAS 文件管理器里的项目配置目录不等于资料卷。
    • 浏览器 用 HTTPS 地址访问服务。/setup/ 仅用于首次初始化，完成后永久关闭。rc.4 已正确挂载静态包时根路径 / 提供登录/首页；旧 rc.2/rc.3 无业务页面时根 404 可以正常。
    • 自己的电脑 运行 Lantai CLI、Codex 和本地工作目录。--directory、--workspace、会话文件都属于这台电脑，不是 NAS 路径。

    浏览页面与其他操作

    统一包在原核心功能上包含首页、口令/TOTP 登录、权限内项目与资源浏览、显式只读预览和帮助。请按网页与 CLI 步骤操作；实际是否已安装要核对设备的镜像、静态包和网关，不能只看本页版本。

    网页在线备份入口、运行中备份的主动取消、外部盘自动预检、安装/升级全过程的卷身份绑定保护均仍是设计。现有本机 backup -cancel 只能在取得锁后取消记录，不等于可打断另一个正在运行的备份进程。详见能力边界。

    阅读与保存

    统一包的帮助入口为 /help/，可搜索本手册、按目录跳转或用浏览器打印保存。该帮助目录是公开通用内容，不读取会话、项目或服务器配置。rc.3 原始部署模板没有这个路由，访问 404 时可直接阅读仓库中的本手册；不要因此重装实例。

    每页顶部的“返回兰台”回到同一个站点的主应用，由主站按会话显示首页、登录页或连接错误。离线副本只用于阅读，返回服务时请使用自己保存的服务地址。
