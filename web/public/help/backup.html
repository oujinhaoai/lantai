    任务 09文档核对 · 2026-10-21

    备份与恢复

    目标：在获准窗口通过网页生成并核验完整保护点，分别记录备份和独立恢复。完整包具有敏感恢复能力，必须私密保管；不要把包本体、私钥、恢复材料或临时下载授权放进公开验收记录。普通成员与 Agent 没有整馆备份权限。

    网页备份前提

    本人以管理员账户登录，明确勾选“管理员登录（含备份管理权限）”。设备管理员已经为原 core 配置受保护的外部备份目录、目录身份与权限；普通用户不需要编辑 Compose 或运行容器命令。目录不可用时先联系设备管理员，不改服务卷或创建替代实例。

    路径为侧栏“备份与恢复”→“备份管理”。备份会排空请求并暂停全部正常业务读写，先协调测试窗口；仅使用专用合成实例不能推定获准暂停真实业务。

    立即备份与实际下载

    1. 读取“备份目录”，确认“可用”；核对当前任务与上次成功记录，不能把上次成功当成本次成功。
    2. 点“立即备份”，核对服务器的暂停说明与全部目标。在“确认操作的验证器动态码”输入新的当前码，点“验证并执行”。动态码只留在当前确认框。
    3. 等当前任务终态为“已完成并验证”，核对“完整恢复包已生成并验证”、捕获时间、大小与 SHA-256。
    4. 需要下载时点“下载完整恢复包”，完成该下载动作的独立确认。实际保存后核对文件大小与完整摘要；下载点击、链接签发或浏览器任务出现不代表完整字节已保存。
    5. 私有记录分别保存“任务标识”job.id 和“备份标识”backup_id。它们不同；升级迁移所需的 NAS 目录是原备份 bind 宿主来源目录加完成任务的 job.id，该目录直接含 manifest.json。不要填 backup_id、裸 ID 或电脑上的下载路径来替代 NAS 输出目录。

    成功标准是本次任务完成且包校验通过；下载验收另看实际字节。恢复未执行时必须填“未测”，不能由备份成功自动勾选。

    计划、取消与续传

    “每日计划”按实际填写 IANA 时区、当地时间、排空等待上限和任务超时，再“验证并保存计划”；保存须新鲜敏感动作确认。只在获得计划运行授权时启用，不因手册示例开启真实实例的定时任务。

    失败、取消或重启中断时保留原任务和部分副本，修复原因后点“续传此任务”并重新确认。取消请求受理后仍须等实际退出，cancelling 不表示已恢复正常写入。不要换一份包续传原任务，不删除 pin、锁或伪造 COMPLETE。

    普通会话到期时，页面若进入“备份维护身份验证”，用本人原账户、口令与新动态码重新验证。此临时身份仅查询/取消当前任务，不开始新备份、不修改计划；备份结束或 core 重启后返回正常登录。

    独立恢复的人工验收

    r10 候选实现了新空目标上的完整包安装/恢复向导；它不是已经完成 NAS 恢复的证明，也不是旧 rc.6 的能力。恢复会改变目标环境，必须由获准的设备管理员单独安排兼容版本、隔离空目标与恢复用例，不在源实例或真实业务卷上试点。

    在该受控用例中，管理员核对空目标后从受保护的 /setup/ 选择“从完整备份恢复”，上传可信完整包，核对实例/捕获点/清单，设置新的管理员因素，完成领域/文件检查及明确恢复点接受后，再检查重开、固定版本字节和重启。未实际完成的步骤保持未测/阻塞，不能把上传成功当作恢复接受。具体向导能力见首次设置；普通验收人员不据此自行操作真实卷。

    恢复验收的边界

    • 备份生成不等于恢复。 必须有独立目标上的管理员因素确认、恢复接受、历史版本/文件摘要重读与重启证据；选定范围不代表全馆或真实 DCC 续做。
    • schema14→15 后，旧核心不能同卷换旧镜像降级。保留升级源卷和已核验的旧保护点，不能清空数据或伪造版本记录。
    • 已验证的旧 rc.6 格式独立卷恢复涉及 recover-admin、新因素、绑定证据的 restore-complete 和恢复目标自己的配置。NAS 纯 GUI 旧版恢复尚未验证，相关操作入口仍有缺口。 本轮 Web 更新未新增这些能力，不提供一个声称可直接完成旧版纯 GUI 回退的按钮顺序。
    • 新格式完整包与旧数据快照不同。不能把旧快照改后缀充当包，不能用旧宿主配置覆盖恢复器生成的目标配置；损坏、非空目标或不兼容时保持停止。
    • 恢复点之后未知的撤权、删除、外部副作用和本机未保存操作仍需对账；恢复不会自动清除 unknown，也不会复活旧会话或机器授权。

    记录与停止条件

    证据记录 job.id、backup_id、捕获点、包大小/摘要、任务终态、独立恢复范围及未覆盖事项。目录缺失、容量不足、摘要错误、恢复未完成、实例或代际不符时停止；由设备管理员保留现场处理，不关闭安全校验。可复制空白验收记录。高级部署与命令另见运行中备份说明，不作为普通网页使用前提。
