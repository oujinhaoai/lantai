    管理工作台的五个入口

    本页描述本次开发候选中的管理功能，不表示已发布版本或实际设备已具备。使用前核对同一包的核心、静态页面和网关。真实资料迁移、设备助手安装与整馆恢复需要各自的授权和现场验收；本轮测试仅使用合成数据。

    登录与权限

    普通浏览只申请 self/read。需要入藏或编辑时，登录时明确勾选“素材管理”；系统管理员再明确勾选管理员范围。页面不会自动扩大权限。项目角色、会话范围与当前授权共同决定操作；管理员不自动成为项目负责人。没有标签页校验时重新登录，不复制会话或授权地址到业务记录。

    五个主入口是“素材库”“迁移中心”“工程工作集”“备份与恢复”“系统管理”。备份入口仅向适用的本人管理员浏览器会话显示；系统入口还按会话范围显示，真正授权仍由每次服务器请求核验。

    素材库

    项目、类型、关键词和精确标签由服务端组合筛选。标签可重复，按精确 AND 匹配；空页有下一页游标时仍须继续。打开资产后按历史列表或固定版本 ID 切换，分享固定链接；当前著录与历史冻结清单分别显示。

    编辑标题、摘要、标签和画像时以原修订为基线。并发冲突保留草稿，由本人重读合并，不覆盖他人修改。导出的草稿属于私有资料。提交了文件而初始著录未完成时，保留原 operation 和状态补办，不能新建一份上传来代替。

    画像可管理角色、来源、业务状态、历史状态、历史版本、来源路径和笔记，并保留画像格式标识及其他未知著录。画像只改变普通著录；历史“已通过”不授予制作、导出或发布权限。用途与权利页读取当前核心判定，追加来源证据、收紧限制、更正或解除限制走各自领域动作；放宽时仍须新证据和动作绑定的人审挑战。

    缩略图和代理只处理 PNG/JPEG/WebP，原图最多 16 MiB、16,777,216 像素；缩略图最长边 320，代理可选 512/1024/2048。生成前完整核验原件，导出另请求 raw_export，不自动转换用途。OBJ 仅提供不加载外部材料的线框查看，最多 2 MiB、20,000 顶点、60,000 边；其他 3D 格式明确不支持。版本比较展示固定清单差异，不运行原生工程或推断语义相同。

    迁移中心

    先显式选择文件并核对来源清单、路径、分组、项目映射和权利条款；未选、排除、未知项均需保留。旧标签或“已通过”字样只作为历史著录，不能转换成核心审定、发布或许可结论。

    容量预检区分逻辑字节、上传暂存及备份/恢复需求。管理员可读到的数据卷空闲量不代表备份目录、安装卷或用户电脑有足够空间；未知容量保持未知。浏览器批次最多 256 个文件、单文件 64 MiB、合计 256 MiB，大批次使用显式本机作业。

    浏览器状态只使用自身的明确格式，不与任意 CLI 状态互导。原生计划若含页面重编码会改变的数字或转义词法，页面会拒绝续办；保留原文件，使用助手 input_file 交接，不重算原摘要或操作键。

    开始前下载并保存原操作状态。断线、取消或结果不明时导出最新状态，沿用原键和原输入继续；取消不代表服务端已回滚。计划、结果和失败项可保存为馆内 config 档案，条款仅适用于生成的私人记录，不修改原素材权利。

    入藏回执只是历史事实。迁移完成前按固定资产/版本逐文件核对大小与 SHA-256，并使用独立验证目录或明确选中的本地文件检查原件；页面的远端核验与本机助手结果分别显示。关联备份和恢复证据后，仍不能据此删除来源或宣称原生工程可继续编辑。

    批次使用与切换台账记录责任人、最后动作、阶段和接受状态；每次修改追加同一档案资产的新版本并绑定上一修订。必须保留全部导入行，失败、未知和未开始项不能从清单消失。明确选择预期用途、固定工作集、当前验证及完整包恢复档案，然后请求服务端复核。核心只在全部检查通过时给出当前固定范围的 ready 观察；原生软件打开编辑回交未验证、恢复点之后未知、缺证据或不明设备副作用均阻塞接受。人工责任勾选不会覆盖这些门禁。

    选中笔记的改链先计划，审阅原计划后创建独立副本；回退再创建第三份独立副本，保留原件、改链副本及明确列出的切换后新成果库存。网页通过已认领设备实际派发，不会直接改写原笔记或推断全库引用已覆盖。完整计划含本机来源，只在本机审阅；后续动作使用原结果引用和摘要，仍须网页逐个批准。

    工程工作集

    工作集固定每个资产的精确版本、目标相对目录、入口与依赖，不跟随最新版漂移。支持导入、导出、馆内保存和重新读取；读取时复验当前实例、清单、权限和文件摘要。

    浏览器在预算内下载 TAR，不自动解压到本机目录，也不能证明本机目标没有冲突。大工程通过本机助手复用原 CLI 的路径冲突、断点和 Range 下载检查。依赖分析仅解释页面列出的 OBJ/MTL 和受限 ComfyUI JSON 字段；不执行脚本，不推测未知格式或访问外部 URL。缺失、外部或不支持的引用需由人处理。

    回交新版本时明确选中工作集条目及固定基线，选择完整新文件并确认内容权利，保存原操作状态后上传提交。基线冲突保留原键与状态，停止并要求重读；不自动换基线。提交成功后可另行明确创建工作集修订以采用新版本，原工作集及旧版本继续保留。

    备份与恢复

    原立即备份、每日计划、取消、续传和完整恢复包流程保留。完整包具有敏感恢复能力，应私密保管。

    恢复核验从核心读取实际已完成的恢复接受回执，再对本次选定的固定版本做逐文件核验。历史回执、完整包校验、当前文件可读与原生软件续做是不同证据。只选了部分版本时，输出只覆盖所选范围；恢复点之后未知事项保持未知。导入的旧档案不会自动成为本次通过结论。

    系统管理

    系统页提供项目创建、明确项目 ID 的成员读取与角色授予/撤销、管理员主体和凭据元数据查询，以及审定、发布、回收站和审计入口。创建项目后仍须明确授予成员，系统管理员不会自动取得素材访问角色。

    敏感动作先冻结目标、修订和完整请求，再显示服务端挑战并输入新的 TOTP。HumanGrant 只在当前内存中，导出诊断不包含授权。丢失响应时保留原 operation/幂等键核对；重新挑战仍绑定原动作，不盲目改键。回收、恢复、保留和发布使用原领域规则；入藏或编辑成功不等于人审通过。

    受控本机助手

    本机先明确选择私有工作区、目录别名和允许的八动作子集，使用原口令/TOTP取得独立、单项目、最长15分钟的本人 CLI 会话，再运行 configure/enroll/worker。系统管理的设备页使用另一个本人网页会话核对一次码、项目、工作区别名和绑定摘要。网页不接收本机凭据，也不能选择任意宿主路径。

    网页创建作业后，设备只读 inspect 并回报精确批准摘要；人明确批准后，设备才从核心领取唯一 JobAttempt/fence 执行。完整原计划通过本机只读 result 命令审阅，网页只保留绑定结果引用。worker须明确启动，只向既定 HTTPS 网关发出请求；严格证书与主机名校验，私有 CA 仅供该客户端。文件交接的 inspect/run 方式继续可用。

    取消、到期、撤权或失联时保留原作业、输入与操作键；已派发且副作用不明不能当作未执行或自动换键重试。重启只续办原状态，丢失结果响应只重发原结果。助手不执行任意 shell、不监听本机端口、不自动安装或启动系统服务、不移动或删除来源，也不构成操作系统安全沙箱。本轮仅合成设备测试；真实电脑安装、生产凭据或NAS访问仍须另行明确授权。完整命令与协议见随包的助手说明及设备协议。
